# Girl in the Cloud

**Alisha Pandit · Aspiring Cloud Engineer**  
Soft aesthetics. Strong architecture.

A personal portfolio built around an illustrated cloud atlas. Four project islands open individual engineering case studies. A miniature desk, architecture layers and achievement diary introduce Alisha’s work and learning goals.

![Isometric cloud workspace](frontend/public/art/hero.svg)

## Run locally

From the repository root, with Python 3.12:

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --reload
```

On Windows PowerShell, activate with `.\.venv\Scripts\Activate.ps1`. Open **http://localhost:8000**. The local app creates a SQLite database. The public pages, original illustrations and keyboard controls work before the optional WebGL bundle is built.

With Node 22, build the React workspace and local web fonts:

```sh
cd frontend
npm install
npm test
npm run build
cd ..
```

Restart the server after the first frontend build. To run the PostgreSQL and Nginx stack, see [deployment instructions](DEPLOYMENT.md).

## Maintain

Edit the personal content in `content/portfolio.json`. Place Markdown articles in `content/blogs/`. Artwork is generated by `python scripts/art.py`. Source-controlled configuration contains public information only.
